# Learner profile

Your AI agent copies this template to `my/profile.md`, which is never committed, and fills it in. It works from what it knows about you, or from a short interview. Every question it writes is tailored to this file. Edit it as you grow.

- Role and daily work: what you build, your stack, the systems you touch every week.
- Language: which language to write questions in. Today, Python 3.12, standard library first.
- Goal: what you want to get better at, and why. For example: staff-level depth in distributed systems, or ramping up on a new domain.
- What your AI does for you at work: the parts you no longer write or read yourself, such as tests, concurrency code or SQL. Whetstone practises these first, because unused skills fade fastest.
- Preferences: for example, an analogy first, or the real mechanism straight away. Name a domain to tie examples to, if you have one.
- Writing style: for example, short sentences, active voice, one idea per sentence.
